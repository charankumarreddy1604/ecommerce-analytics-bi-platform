# 📊 E-commerce Analytics & BI Platform

A web-based Business Intelligence (BI) dashboard designed to analyze e-commerce sales data, monitor revenue, identify top-selling products, and understand regional and category-wise performance.

## 🚀 Project Overview

The E-commerce Analytics & BI Platform helps users convert sales data into meaningful business insights through interactive charts, KPI cards, filters, and downloadable reports.

This project uses HTML, CSS, and JavaScript to build a responsive frontend dashboard with sample e-commerce data.

https://charankumarreddy1604.github.io/ecommerce-analytics-bi-platform/

## 🎯 Objectives

* Analyze total sales revenue and orders.
* Track the number of products sold.
* Monitor unique customers.
* Compare category-wise and region-wise sales.
* Identify top-performing products.
* Filter sales records and export reports as CSV.

## 🛠️ Technologies Used

* **HTML5** – Webpage structure
* **CSS3** – Styling and responsive layout
* **JavaScript** – Dashboard logic and filtering
* **Chart.js** – Interactive charts
* **GitHub** – Source code hosting

## ✨ Features

* Interactive sales dashboard
* Revenue, orders, units sold, and customer KPI cards
* Revenue trend chart
* Category-wise sales analysis
* Regional performance chart
* Top products by revenue
* Searchable sales transaction table
* Region, category, and date filters
* CSV report download
* Responsive design for desktop and mobile

## ⚙️ Installation and Usage

### Step 1: Clone the repository

```bash
git clone https://github.com/charankumarreddy1604/ecommerce-analytics-bi-platform.git
```

### Step 2: Open the project folder

```bash
cd ecommerce-analytics-bi-platform
```

### Step 3: Run the dashboard

Open `index.html` in your web browser.

You can also use the VS Code Live Server extension to run the website locally.

## 📈 Dashboard Modules

1. **Sales Overview:** Displays revenue, orders, units sold, and customers.
2. **Revenue Analysis:** Shows changes in revenue over time.
3. **Category Analysis:** Compares sales across product categories.
4. **Regional Analysis:** Displays revenue by region.
5. **Product Analysis:** Identifies top-performing products.
6. **Sales Transactions:** Displays searchable sales records.
7. **CSV Export:** Downloads the filtered sales data.

## 🔐 Data and Security

The current version uses sample data stored in `script.js`. No real customer database is connected. Real customer information should be protected, and database credentials must never be committed to a public repository.
